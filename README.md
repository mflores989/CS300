# CS300
Throughout this course, the primary problem I worked to solve was developing an advising assistance program for the Computer Science department at ABCU. The program needed to read course information from a file, organize courses in alphanumeric order, and allow academic advisors to search for specific courses and their prerequisites. I approached this problem by evaluating three data structures: vectors, hash tables, and binary search trees. Through runtime analysis using Big O notation, I compared their efficiency, memory requirements, and limitations. I ultimately selected a binary search tree because its in-order traversal naturally displays courses in alphanumeric order while also supporting course searches. Understanding these data structures helped me recognize that choosing the appropriate structure is an important part of software development because it directly affects program performance, organization, and functionality.

I encountered challenges involving program logic, implementing the binary search tree, and ensuring that the application handled invalid data correctly. I worked through these challenges by reviewing my pseudocode, troubleshooting errors, and breaking larger problems into smaller, manageable functions. I also incorporated input validation, duplicate course detection, and prerequisite verification to improve the program's reliability. These experiences expanded my approach to software development by teaching me the importance of planning and analyzing a solution before beginning implementation. I have also developed a better understanding of how to write maintainable, readable, and adaptable code by using meaningful variable names, comments, and separate functions for specific tasks. Moving forward, I will apply these practices to develop programs that are easier to troubleshoot, modify, and expand as requirements change.
